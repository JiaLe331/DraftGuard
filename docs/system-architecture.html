DraftGuard

Technical Stack

Target architecture. Google Cloud Run hosts the frontend web application and the backend API. The React frontend exchanges REST API requests and responses with FastAPI. The backend reads and writes application data and documents in Supabase, and calls Google Gemini for AI assistance. Gemini has no direct database connection.
